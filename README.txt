# NovaCart - Responsive Multi-Brand E-Commerce HTML Template

NovaCart is a modern and fully responsive front-end eCommerce template designed for showcasing and selling tech products. Built using HTML5, CSS3, and Vanilla JavaScript, it features a sleek dark/light theme switcher, smooth animations, and a clean, user-focused layout.

---

## Key Features

- 100% Responsive Design
- Dark/Light Mode Toggle
- Scroll-Based Reveal Animations
- Product Showcase Cards
- Brand Carousel Grid
- Testimonials Section
- Contact Form UI (No Backend)
- Animated Hero Section
- Mobile-Friendly Navigation
- Clean & Commented Code

## 🚫 Limitations

This is a **front-end-only** template.
- No database or backend functionality is included.
- The contact form is static (non-functional).

You may integrate your own backend (PHP, Node, Firebase, etc.) if needed.

---

## 🔧 How to Edit

1. Open `index.html` in any code editor.
2. Replace product/brand info inside appropriate sections.
3. To add images, put them inside the `/images` folder and update the `<img src="">` paths.
4. Customize styles via `/css/style.css`.
5. Adjust JavaScript in `/js/script.js` if needed (theme toggle, scroll animations, navbar toggle).
